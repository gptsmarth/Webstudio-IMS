# Quick Start Guide (M14I)

Get productive in **15 minutes**. For full detail see the [User Manual](USER_MANUAL.md).

---

## Step 1 — Open the app (2 min)

### Desktop (counter PC)

1. Start **WEBSTUDIO Desktop** from the Start Menu or Applications.
2. Wait until the toolbar shows **Online** / **Connected**.
3. Log in with username and password from your manager.

### Mobile (floor)

1. Open **WEBSTUDIO IMS** on your phone.
2. On first use, enter server address if asked: `http://<server-ip>:8000` (get IP from admin).
3. Log in.

**Stuck?** Check Wi‑Fi is the same network as the store server. Ask IT if status stays Offline.

---

## Step 2 — Find a laptop (3 min)

| Platform | Fastest method |
|----------|----------------|
| Desktop | Press **Ctrl+K** (Mac: **Cmd+K**) → type serial or model → Enter |
| Mobile | **Inventory** → search box → type serial |
| With scanner | Focus serial field → scan barcode |

Open the result to see **status**, **location**, and **specs**.

| Status | What it means |
|--------|---------------|
| **Available** | OK to sell |
| **Sold** | Already sold — stop |
| **In transit** | Moving between floors |

---

## Step 3 — Know your dashboard (2 min)

After login, the **Dashboard** shows:

- How many laptops are **available** vs **sold**
- **Recent** inventory changes
- **Notifications** (red badge if unread)

Click the sidebar:

- **Inventory** — all stock
- **Sales** — completed sales
- **Search** — same as Ctrl+K on desktop

---

## Step 4 — Common daily tasks (5 min)

### Sales staff — look up before quoting

1. Customer asks about a unit → **search serial**.
2. Confirm **Available** and **location** (e.g. Ground Floor).
3. If **Sold**, check **Sales** for invoice date.

### Warehouse — receive a unit (if you have permission)

1. **Inventory** → **Add laptop**.
2. Scan or type **serial**.
3. Pick **brand**, **model**, **colour**, **location**.
4. **Save**.

### Move stock between floors

1. Find item → **Transfer**.
2. Choose new **location** → confirm.

### Sales from billing (Tally)

You usually **do nothing** — when accounts print an invoice in Tally, the server imports it automatically. Check **Sales** after sync. Tell admin if sync health shows **Offline** all day.

---

## Step 5 — Barcode in 30 seconds

| Where | How |
|-------|-----|
| Desktop + USB scanner | Click serial field → scan (scanner types like keyboard) |
| Mobile | Tap **scan** icon → allow camera → point at label |

---

## Step 6 — When something fails (3 min)

| Problem | Do this |
|---------|---------|
| Cannot log in | Caps Lock off → ask admin to reset password |
| App Offline | Wait 30 sec → check Wi‑Fi → tell admin |
| Serial not found | Double-check label → item may not be received yet |
| Already sold | Show customer **Sales** record — may be duplicate check |

More: [FAQ](FAQ.md)

---

## Cheat sheet

```
LOGIN     → username + password from admin
SEARCH    → Ctrl+K (desktop) or Inventory search (mobile)
AVAILABLE → safe to sell
SOLD      → do not re-sell
TRANSFER  → item detail → Transfer
HELP      → admin / manager / User Manual
```
