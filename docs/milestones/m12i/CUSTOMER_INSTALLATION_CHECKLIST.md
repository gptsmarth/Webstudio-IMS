# Customer Installation Checklist

Step-by-step checklist for end customers installing WEBSTUDIO IMS after the server is deployed by your integrator or IT team.

**Audience:** Shop owner, office manager, or staff performing client installs.  
**Detailed guides:** [INSTALLATION_GUIDE](../m12h/INSTALLATION_GUIDE.md) · [DESKTOP_GUIDE](../m12h/DESKTOP_GUIDE.md) · [ANDROID_GUIDE](../m12h/ANDROID_GUIDE.md) · [IOS_GUIDE](../m12h/IOS_GUIDE.md)

---

## Before you start

- [ ] IT has provided the **server address** (e.g. `192.168.1.50` or `WEBSTUDIO-SERVER.local`)
- [ ] IT has created your **username and password**
- [ ] You are on the **same office Wi‑Fi or LAN** as the server
- [ ] You have administrator rights on your PC (desktop install only)

---

## Windows desktop

1. [ ] Obtain `WEBSTUDIO Desktop Setup.exe` from your IT team or shared drive
2. [ ] Run the installer; accept defaults unless IT specifies otherwise
3. [ ] Launch **WEBSTUDIO Desktop** from the Start Menu
4. [ ] On first launch, enter **server address** when prompted (or use auto-discovery)
5. [ ] Log in with your username and password
6. [ ] Confirm dashboard loads and your role-appropriate menu appears
7. [ ] (Optional) Pin shortcut to taskbar

**Uninstall:** Settings → Apps → WEBSTUDIO Desktop → Uninstall

---

## macOS desktop

1. [ ] Open `WEBSTUDIO Desktop.dmg`
2. [ ] Drag **WEBSTUDIO Desktop** to Applications
3. [ ] If macOS blocks the app: System Settings → Privacy & Security → Open Anyway (after IT notarization)
4. [ ] Launch and connect to server as above

---

## Android phone / tablet

1. [ ] Enable **Install from unknown sources** only if IT directs (sideload APK)
2. [ ] Install `WEBSTUDIO-Android.apk` or download from Play Store when published
3. [ ] Open app → enter server address → log in
4. [ ] Allow **camera** permission when using barcode scan
5. [ ] Confirm you can search inventory and view assigned screens

---

## iPhone / iPad

1. [ ] Install via link or TestFlight / App Store per IT instructions
2. [ ] Open app → enter server address → log in
3. [ ] Allow **camera** for barcode features
4. [ ] Confirm sync and dashboard for your role

---

## First login (all clients)

- [ ] Change password if prompted
- [ ] Verify correct **company name** appears in header or settings
- [ ] Test one everyday task (e.g. search product, record sale — per your role)
- [ ] Note IT support number if anything fails

---

## Troubleshooting quick checks

| Symptom | Check |
|---------|--------|
| Cannot connect | Server address spelling; same Wi‑Fi; server powered on |
| Login fails | Caps Lock; ask IT to reset password |
| Blank dashboard | IT may need to assign permissions to your user |
| Tally data missing | Tally integration is server-side — contact IT |

**Full troubleshooting:** [TROUBLESHOOTING_GUIDE](../m12h/TROUBLESHOOTING_GUIDE.md)
