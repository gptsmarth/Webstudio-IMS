# Desktop Applications

## Purpose

Parent directory for platform-specific desktop client applications (Windows and macOS).

## Expected Files

- windows/ — Windows desktop application
- macos/ — macOS desktop application

## Audience

Desktop developers, architects

## Guidelines

Shared desktop logic should live in packages/. Platform-specific code stays in each platform folder. No application code until development phase begins.
